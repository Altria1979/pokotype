# 品牌图标统一

页头标识与浏览器标签图标统一为专门绘制的「折纸 P + 输入光标」。P 对应 Pokotype，右上折角呼应纸感主题，右下短竖条表达打字输入。以朱红 `#ac481e`、米白 `#fffdf8` 为主色，折角使用暖纸色 `#e7b596`。采用固定 SVG 几何路径，保留桌面 38px、手机 33px 占位。

## 改动文件

- `public/icon.svg`：用原创折纸图形替换「ぽ」文字标识，提供共用矢量图标。
- `src/components/Shell.tsx`：页头复用图标，保留品牌链接的可访问名称。
- `src/components/Shell.module.css`：共用 SVG 背景，删除原有边框、字形与旋转样式。
- `src/app/layout.tsx`：声明 SVG 类型及任意尺寸，增加版本查询参数刷新旧图标缓存。

# 文章练习模式

文章详情支持逐句、分组、整篇三种练习方式。首次默认整篇；模式和分组句数保存在当前浏览器中。分组可选每组 3、5、10 句，默认 3 句。

## 交互

- 文章预览以一篇连续日文正文呈现，保留假名；中文译文集中在正文下方。不再在阅读时逐句编号或穿插翻译，修改读音时仍按句子编辑。
- 页面按「文章预览与译文 → 选择练习方式 → 开始文章练习」排列。整篇选项排在首位，首次默认选中，并保留之后手动选择的模式。开始入口位于模式面板底部中央，以宽按钮呈现；编辑或保存时禁用，电脑、手机和 iPad 均可开始三种模式。
- 逐句每次显示一句，沿用原有声音偏好和计时方式。
- 分组按连续、不重叠的句子窗口展示，末组保留剩余句子；整篇展示所有句子。正文连续排版，已完成部分保留为绿色，当前词组高亮。
- 两种连续模式自动跨句、跨组，不需要 Enter。长文和长提示分别滚动，只在当前输入位置离开容器可视范围时跟随。
- 罗马音提示和中文翻译跟随当前句；假名、翻译、罗马音提示开关继续可用。短视口压缩正文高度和垂直留白，为输入提示保留空间。
- 电脑进入练习后直接敲键；手机和 iPad 点题目或罗马音区域唤起系统英文 26 键键盘，也可使用外接实体键盘。软键盘弹出时优先显示当前正文、输入提示和暂停操作，次要选项收进「练习设置」；连续模式仍保留已完成内容和输入位置跟随。网站不能自动切换键盘语言。
- 开始时固定本轮模式和组大小。提前结束不保存成绩；返回后可以更换模式，下一轮从第一句开始。

## 声音与计时

分组、整篇的分段朗读在开始时沿用声音设置（默认开启，尊重已保存的关闭偏好），每完成一个片段就朗读该片段，朗读时可以继续输入，计时不中断。整句听读仍默认关闭。练习中的两个朗读开关只对本轮生效，不覆盖逐句偏好。按键音继续使用既有设置。

连续模式从首次正确输入开始计时，跨句、跨组及之后的错键等待均计入。暂停、窗口失焦和整句听读期间不计时；听读结束或跳过后恢复，若仍暂停则保持停表。最后一个正确键停止计时。完成整篇仅保存一条成绩，迟到的听读回调不会跳过句子或重复保存。

## 数据与兼容

- `ArticlePracticeMode` 为 `sentence | group | full`，`ArticleGroupSize` 为 `3 | 5 | 10`。
- 偏好新增 `articlePracticeMode`、`articleGroupSize`；旧偏好缺失或无效时回退到整篇、3 句。
- 练习记录继续使用 `mode: article`，新增可选模式和组大小；组大小仅在分组记录中写入。旧记录缺失文章模式时展示为逐句。
- 不改变文章内容协议、数据库版本或罗马音引擎。原始内容只保留句子顺序，没有自然段元数据，因此称为分组练习。

## 变更文件

- `src/components/Articles.tsx`、`Articles.module.css`：模式入口、偏好记忆和本轮配置。
- `src/components/Practice.tsx`、`Practice.module.css`：正文窗口、输入跟随、局部声音开关和结果模式。
- `src/components/History.tsx`：新旧成绩的模式标识。
- `src/lib/article-practice.ts`、`practice-run.ts`、`storage.ts` 及对应测试：共享类型、分组窗口、连续计时与存储兼容。
- `tests/article-modes.spec.ts`：模式行为和短视口回归；既有文章输入和音频用例显式选择逐句模式。

三种模式共用原有判定及计分逻辑，通过显示窗口切换练习范围，没有引入新的匹配引擎或依赖。

## 分段朗读修复

整篇练习中完成片段却没有发音，是连续模式将本轮分段朗读强制初始化为关闭，覆盖了已开启的声音偏好。改为在开始时读取 `articleSegmentSpeechEnabled`；全局明确关闭时仍保持关闭。复用原有片段完成回调及语音播放逻辑，无需更改罗马音判定、计时或存储结构。

浏览器回归增加整篇和分组的片段完成、未完成/错键静音、日语语音调用、朗读期间连续输入与计时、句末及跨组推进、最后片段、取消及迟到回调和本轮设置隔离。

此次修复通过 Lint、类型检查、326 项单元测试及静态构建。`audio-practice.spec.ts` 与 `article-modes.spec.ts` 共 34 个浏览器场景最终分批通过：首次 33 项通过，一项因测试错误假定默认偏好必已写入存储而失败；修正为比较本轮前后存储不变后，两种模式的相关用例复测全部通过。旧构建上的新回归能复现未触发朗读；修复构建验证了传入语音 API 的日文及 `ja-JP` 语音。报告与默认开关截图位于 `.omx/artifacts/article-segment-speech/`。

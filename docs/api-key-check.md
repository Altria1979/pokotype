# 可发现的密钥配置与连接检查

设置页同时显示 DeepSeek API 密钥、阿里百炼 API 密钥两张卡片，不必先切换服务才能找到配置入口。各卡片分别保存、清除和检查；「已保存·未检查」「检查通过」「检查通过（未保存）」区分本地配置和接口鉴权。

检查成功后，各卡片显示「查看模型列表」。点击后在弹窗中展示该次检查返回的模型 ID 和数量，长列表可在弹窗内上下滚动，关闭按钮始终可见。未保存的草稿密钥也能查看列表；打开弹窗不会再请求接口、保存密钥或切换生成模型。关闭按钮、Esc 和点击遮罩都能关闭并返回入口焦点。编辑、清除密钥或重新检查后，旧列表及弹窗失效。检查后保存同一未改动的草稿密钥会保留验证结果并同步生成选项，无需再次检查。

检查使用输入框里的草稿密钥，输入框为空时使用已保存密钥。检查草稿不会自动保存。只在用户点击检查时请求官方模型列表，不自动发请求、不消耗文章生成额度，也不保证生成余额或全部模型权限。

- DeepSeek：`GET https://api.deepseek.com/models`。
- 百炼北京：`GET https://dashscope.aliyuncs.com/compatible-mode/v1/models`。
- 固定端点、禁止重定向、20 秒超时、支持取消；错误不回显原始服务响应。
- DeepSeek 和百炼已保存密钥检查成功后，均以返回目录作为模型选项，设置与生成弹窗共享；不改用户已选择的模型，仍允许自定义 ID。
- 目录仅内存保存。密钥编辑、清除或跨标签页变化会清掉旧目录及检查状态；保存未验证的密钥也会清除目录。取消或迟到响应不发布过期结果。
- 百炼仅在尚未获取目录时显示 Qwen3.7/3.8 Flash 预设；获取后展示全部返回 ID，并提示文章生成应选择支持文本对话的模型。

## 百炼生成选项同步修复

根因是 `AiModelFields` 仅允许 DeepSeek 使用已取得的目录，百炼始终回退到两个预设。现已去掉这个服务判断，两家在设置页和生成弹窗中都复用同一目录与数量提示。同时，`ApiKeyCard` 保存已验证且未修改的草稿密钥后保留结果并发布目录；检查不会自动保存，保存不会再次请求接口。

未取得目录时仍显示预设；目录仅当前页面会话有效。百炼返回的目录可能包含不同用途模型，列表展示不代表每一项都适合文章生成，界面提示选择支持文本对话的模型。

验证：lint、类型检查、静态构建和 326 项单元测试通过；相关 28 项浏览器回归全部通过。226 模型模拟用例验证了列表弹窗与两处生成选项数量一致、保存无需重复 GET、跨页面同步、选中非预设模型后的 POST 使用该模型 ID，以及换密钥、清除和失败后的目录失效。未重复调用真实服务。

# Pokotype 纸感风格重构（初版历史记录）

> 当前视觉规范已由 [纸面与颗粒返工](paper-rework.md)替代。初版纸纹过弱，旧视觉评分 94/pass 已被后续截图与用户反馈证伪，相关“视觉通过”结论作废。以下设计参数和测试结果保留用于追溯初版，仅能作为历史功能检查，不能证明当前版本的视觉相似度或测试状态。

## 初版批准计划（视觉参数已被返工替代）

将现有 Rounded Arco 界面改为参考 Petrichor 宣传页的米白纸感界面，保留 Pokotype 品牌、五十音首页和所有已有功能。只修改本地项目，不创建 Git 仓库、推送或部署。

1. 引入固定版本 UI Sift，保留许可及必要引用文件；建立项目纸感样式 Skill。
2. 统一语义化主题变量，将侧边栏改为顶部导航。页面最大宽度 1280px，桌面左右 48px、手机 20px；900px 以下采用可键盘操作的折叠菜单。
3. 依次更新五十音设置、练习、AI 文章、文章库与预览、记录、设置及输入规则弹窗。保留当前输入高亮、分组罗马音和全部功能状态。
4. 以已有输入、存储和浏览器回归测试保护行为；补充导航的键盘与移动端测试，检查所有页面的响应式布局。
5. 完成类型、Lint、单元测试、静态构建和端到端检查；保存桌面与手机的前后截图，并检查减少动态效果及控制台错误。

## 设计约束

- 米白画布 `#F4F1EB`，墨黑文字 `#111111`，橙、蓝、墨绿少量点缀；细边框、清晰留白和胶囊按钮。
- 宋体中文标题，易读界面字体，完整日文字形支持，正体等宽罗马音。使用系统字体，不下载未核实许可的官网字体。
- 本地 CSS/SVG 原创装饰；低对比度静态纸纹位于内容后方，练习文字区域不覆盖纹理。
- 不新增依赖，不改变框架、路由、输入判定、计分、DeepSeek 接口或存储字段。练习仍以电脑键盘为主。
- 输入规则弹窗继续保留暂停、焦点约束、关闭后仍暂停和焦点返回行为。

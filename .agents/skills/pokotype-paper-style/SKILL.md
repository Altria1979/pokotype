# Pokotype Paper Style

这是一套适配日语打字学习的纸感界面规范。以 [Petrichor 宣传页](https://petrichor.wl.do/)的可见颗粒纸面、宋体标题、细线和饱和色块为参考，保留 Pokotype 的名称、内容与交互。首页优先引导直接开始练习，完整假名选音卡在下方常显，向下滚动即可浏览；练习时让文字与输入状态保持视觉中心。

## 主题与排版

从 `src/app/globals.css` 的现有语义变量取值；先找已有变量，再新增真正缺失的角色。组件样式使用 CSS Modules，不把以下值重复写到各页面。

| 语义 | 值 / 使用方式 |
| --- | --- |
| 画布 | `#f4f1eb` |
| 普通表面 | `#f4f1eb`，与画布共用纸色和纹理 |
| 浮层与干净阅读面 | `#fffdf8` |
| 主要文字 | `#111111` |
| 次要文字 | `#514e48` |
| 辅助文字 | `#716c62`；不用于降低关键操作辨识度 |
| 主操作 | `#20251f` 实底，浅色文字 |
| 橙色强调 | `#ac481e`，用于短标签和局部品牌点缀 |
| 蓝色 | `#1e5fce`，用于清晰的交互或当前输入提示 |
| 墨绿 | `#235c34`，用于成功状态 |

中文标题、导航及页头介绍采用 `"Songti SC", "STSong", "SimSun", serif`。一级标题随内容区缩放，五十音首页桌面使用44–60px、手机44px；避免文字溢出，并保持桌面首屏能开始练习。表单、操作说明与数字统计使用系统界面字体；日文采用 `"Hiragino Mincho ProN", "Yu Mincho", "Noto Serif JP", serif` 并保留正确语言标记。罗马音采用清晰的系统等宽字体且保持正体；斜体只用于品牌和短英文标签。默认不下载字体，不依赖外部字体服务。

用细边框、留白和字重表达层级。页面标题随屏幕缩放，避免在操作密集区域堆叠大标题。次按钮为细线胶囊，表单和内容块使用克制圆角；避免恢复厚重阴影和大面积蓝色背景。

## 页面结构

- 顶部导航包含品牌与五个已有页面入口：五十音、AI 文章、文章库、练习记录、设置。当前入口使用可见选中状态与 `aria-current`。
- 页面使用统一的流式内容宽度，不设整页最大宽度；大于1200px时左右边距64px，701–1200px为32px，700px以下为24px。导航、首页主练习区、选音卡、统计和页尾沿用同一组外边界。滚动超过16px后，导航固定于视口顶部12px并变为胶囊，宽度仍与正文对齐；预留原导航高度，避免内容跳动。900px以下保留折叠菜单、可访问名称、展开状态、键盘操作、Esc关闭和焦点返回；短横屏菜单内部滚动，正文锚点避开悬浮导航。文章正文可保留自身的可读行宽。
- 五十音首页顶部外框铺满可用内容宽度，内容在所有屏幕上均沿中轴上下排列：标题、介绍、假名输入示例、真实范围摘要、快捷设置、开始按钮和次操作。不得将首屏拆成左右双栏；统一模块宽度不等于改变原有垂直布局。主按钮桌面居中、宽320px、高至少60px、字号18px；900px以下铺满，手机与 iPad 同样展示开始和错项强化入口，不按视口宽度限制练习。五层装饰绝对定位于右上角作陪衬，不占用布局列；900px以下隐藏，不与主操作竞争。
- 顶部快捷设置保留题量和罗马音提示，题量选中态使用浅底和边框。平／片假名切换放回下方选音卡，使用横向全宽胶囊和墨绿选中态，同时作用于全部分类；卡片保留纸面细边框与浅绿假名行。范围摘要列出实际分类、部分选择和假名数量；本地偏好加载前禁用上下两处设置与开始，空范围明确提示。
- 完整选音卡置于主练习区下方，与正文同宽，不设1040px上限，始终显示，无需展开操作；卡片标题为“选择练习范围”，允许正常页面滚动浏览所有行。顶部“调整练习范围”只负责滚动与聚焦卡片标题，不使用折叠语义。选音即时保存，底部“返回开始练习”在所有屏幕上滚动并聚焦主按钮；主按钮禁用时返回顶部范围入口。
- 选音卡内按清音、浊音、半浊音、拗音依次纵向常显，不使用分类 Tab 或折叠。每区用具名语义分区、三级标题和细分隔线区分；“全选本类／取消本类全选”仅影响本类，可跨类混选。默认仍只选清音46项，全局全选为107项；保留行ID与存储结构。手机同样常显，拗音组合不换行、不截断，区标题与操作允许自然换行。
- 选音表每个假名下方常显对应的首选罗马音，复用输入引擎既有拼写表；平片假名切换保留相同罗马音。假名用日文字体，罗马音用12px正体等宽字体及次要文字色，两行居中、间隔4px。选音表参考不受练习中的罗马音提示开关影响；手机保持两行完整、不挤压或裁切。
- 进入五十音练习时将焦点与视野移到练习区域，退出后返回主按钮并保留配置。统计、记录入口和 AI 文章推荐置于范围设置之后。不得因布局更新修改声音偏好、输入引擎或存储结构。
- AI 文章桌面采用设置与内容分区，手机纵向排列；文章库与记录优先使用可扫描条目、细分隔线和稳定的元信息位置。
- 页尾使用粉、桃、米、蓝的颗粒渐变波峰，并保留真实入口：AI 文章 `/generate/` 和示例文章 `/articles/?id=sample-morning`。进入练习时隐藏页尾装饰和行动区。

## 纸面材质与装饰

纸纹使用确定性的 256×256 RGBA 灰度噪点图 `public/paper-grain.png`，alpha 固定为 153（60%）。在项目根目录执行 `node scripts/generate-paper-grain.mjs` 可复现同一素材；使用 Node 内置能力，不添加生成依赖。纹理是静态素材，不逐帧随机刷新。

由 `--paper-texture` 统一引用图片。普通纸面使用背景纹理与 `background-blend-mode: overlay`，避免在素材透明度之外再次叠加低 opacity，导致颗粒几乎不可见。文字与控件字形位于干净的上层，不对字形施加 noise、blend 或 blur。

页头装饰采用五层饱和胶囊，顺序角度为 `0 / -35 / 0 / +35 / 0` 度。先叠合彩色形状与径向淡出形成柔边，再覆盖噪点；不能将噪点先画入形状再整体淡掉。装饰不拦截操作，文字标签绘制在颗粒层上方。

### 圆形揭示与指针交互

保持已有布局、纸色、颗粒强度和五层图形。PaperArt 的交互核心是移动圆形揭示区域，五层仅叠加微弱反向视差；不能只移动胶囊来代替揭示变化。噪点始终静态。

- 仅在视口宽度至少 901px、支持 hover 且为精细指针时响应鼠标。监听窗口范围内的鼠标移动，以完整装饰矩形计算横纵归一化位置，并各自夹紧至 `0…1`，不限制在中央小区域。圆心以每帧 `0.08` 的阻尼系数接近目标。
- 揭示区域是真正的圆，而非随容器宽高拉伸的椭圆。以装饰短边计算像素半径：常态为短边的 `0.56`，鼠标位于装饰内时为 `0.72`；对应渐变在半径的 `55%`／`50%` 处达到完全不透明的纸色，并保持外侧纸色遮罩。中心揭示彩色图形，边缘柔和融入纸面，再在上层叠加静态颗粒。
- 鼠标离开装饰矩形但仍位于页面内时，继续使用窗口坐标夹紧后的圆心，只恢复常态半径。不要把装饰自身的 `pointerleave` 当成全局离开。
- `documentElement` 的 `pointerleave`、窗口 blur、页面 hidden 或装饰离开视口时，复位到中心并停止 RAF。触摸、笔输入及 reduced motion 同样保持中心静态状态；恢复满足条件的鼠标交互时再启动必要更新。
- `ResizeObserver` 在尺寸变化时重算短边与像素半径；窗口 resize 与页面滚动也重新映射鼠标坐标，覆盖图案尺寸不变但位置变化的情况。组件卸载时清理观察器、事件监听器和 RAF，避免后台持续更新或重复绑定。

交互验收须检查真实遮罩或伪元素的计算后径向渐变，包括圆形、像素半径、圆心和不透明停止点；还须用截图像素或颜色揭示范围验证移动前后的可见图形变化。仅断言 transform 或 CSS 变量改变不足以证明圆形揭示已实现。覆盖装饰内外移动、全局离开、尺寸改变及静止条件，不在规范中预先宣称测试通过。

## 练习区与状态

练习字形保持干净，不覆盖噪点。日文、假名与罗马音可分辨，当前输入高亮清晰；保留分组之间的视觉间隔，分组不引入需要输入的空格。缩窄窗口时允许内容自然换行，不能裁剪长句或遮住暂停按钮。

样式修改不得改变输入引擎、合法路径、计分、计时、文章内容或数据契约。保留首个有效输入计时、离开暂停、错误不推进、结束未完成不记为完成等行为。电脑、手机和 iPad 均支持实体键盘或系统英文 26 键键盘练习；电脑进入练习后直接敲键，触屏用户点题目或罗马音区域唤起键盘。保留有可访问名称的真实文本控件作为视觉隐藏的键盘接收节点，由点击操作同步聚焦，不增加可见输入栏，也不声称可以强制切换键盘语言。

软键盘弹出时让当前题目、输入反馈与暂停操作留在可视区域，次要选项收进“练习设置”，保持键盘接收节点在题目切换时挂载和聚焦。布局响应可视视口的尺寸及偏移变化；键盘收起、旋转屏幕或外接键盘后仍可继续，缺少相关 API 时保留可滚动布局。自动化设备模拟不能替代 iOS/iPadOS Safari 和 Android Chrome 的真实软键盘验收。

主次按钮、选项、输入框、消息均需覆盖加载、禁用、选中、错误和 `:focus-visible`。错误与成功不只依赖颜色。避免 hover 才出现的关键操作；小屏可触控。减少动态效果偏好下关闭不必要的过渡和动画。

输入规则弹窗保持内部滚动与可见关闭按钮；练习中打开先暂停，关闭后仍暂停并返回入口焦点。不要因主题或导航重排而重建数据 Provider、清空文章草稿或影响焦点约束。

## 验证与维护

视觉调整前先查看相关页面调用和已有回归测试；保持路由、静态导出、存储键和 API 地址不变。局部修改只处理相关界面；不得借样式任务新增依赖、模式或业务流程。

视觉验收使用相同视口的参考与实现截图，检查纸纹强度、饱和色层、径向淡出、标题与留白；纸面灰度统计可辅助定位纹理差异，不能替代截图判断。整站修改覆盖1440px、1920px和390px；流式宽度调整另覆盖320px、768px、1024px及2560px。检查导航滚动状态、长日文、焦点、手机菜单、弹窗、页尾链接、练习时页尾隐藏及受限动效；320px下三语品牌与菜单须保持至少8px间隔，必要时缩小品牌字号。按项目约定运行lint、类型、单元测试、构建和静态浏览器测试，区分已验证与未验证项。

初版视觉评分 94/pass 已被后续截图与用户反馈证伪，不再作为视觉相似通过的证据。初版测试结果仅保留为历史功能检查；本轮验收结论、截图和测试证据以 [纸面与颗粒返工记录](../../../docs/paper-rework.md) 为准，不沿用旧分数，也不提前声明测试通过。

通用重构方法可按需参考相邻 [UI Sift](../ui-sift/SKILL.md)，其组件候选不构成本项目安装新依赖的要求。上游包保持原样；Pokotype 的适配选择记录在本 Skill，而非修改上游文档。初版来源与历史记录见 [重构计划](../../../docs/paper-redesign.md)，当前视觉决策以 [返工记录](../../../docs/paper-rework.md) 和本规范为准。
